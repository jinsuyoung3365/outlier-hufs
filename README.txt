[아웃라이어 실행 방법]

1. 이 폴더(outlier-hufs)를 문서(Documents) 등 원하는 곳에 둡니다.
2. VSCode에서 File > New Window → File > Open Folder 로 이 폴더를 엽니다.
3. Terminal > New Terminal 에서 입력:  python3 server.py
4. 브라우저 주소창:  http://localhost:3000

※ 예전에 켜둔 'python3 -m http.server 3000' 이 있으면 그 터미널에서 Ctrl + C 로 먼저 끄세요.
※ secret.env 에는 카카오 REST API 키가 들어 있습니다. 깃허브에 올리지 마세요 (.gitignore에 포함됨).
※ 서버를 끄려면 터미널에서 Ctrl + C.
