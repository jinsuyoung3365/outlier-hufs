# OUTLIER · 서울 응급실 혼잡도 웹서비스

서울 응급실 혼잡도를 자치구·시간대별로 확인할 수 있는 웹서비스입니다. (2026 한국외대 총장배 이공계 학술제 출품작)

🔗 **서비스 바로가기**: (https://outlier-hufs-1.onrender.com)

> 무료 서버라 첫 접속 시 로딩에 최대 1분 정도 걸릴 수 있습니다.

## 주요 기능
- 실시간 가용병상 연동
- 이동 소요시간과 실시간 병상을 함께 반영한 응급실 순위
- SIR 및 시간대 계수를 반영한 혼잡도 산출

## 사용 데이터
- 국립중앙의료원 응급의료기관 API
- 서울시 자치구별 교통 조사 데이터
- 카카오 REST API (위치 정보)

## 기술 스택
Python · HTML · GitHub · Render

## 담당 역할
기획부터 데이터 처리, 구현, 배포까지 전 과정을 담당했습니다.
- 국립중앙의료원 API 데이터 수집·전처리 및 신뢰할 수 있는 수집 구간 검토
- 교통 조사 데이터를 서울 25개 자치구 단위로 결합
- SIR·시간대 계수를 반영한 혼잡도 산출 방식과 응급실 순위 기준 설계
- Python 서버(server.py)로 카카오 API·실시간 병상 데이터 연동, HTML로 화면 구현
- GitHub로 코드 관리, Render로 배포
- Claude로 코드 초안을 작성하고, 데이터 결합 결과와 화면 출력은 직접 검증하며 수정

## 로컬 실행 방법
1. `secret.env` 파일에 카카오 REST API 키 입력 (깃허브에는 올리지 않음)
2. 터미널에서 `python3 server.py`
3. 브라우저에서 `http://localhost:3000` 접속
